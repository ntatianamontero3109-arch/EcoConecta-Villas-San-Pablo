# EcoConecta 2.0.1 — Sistema visual unificado

Se aplicó un sistema de diseño coherente a las interfaces ciudadana, solicitud,
seguimiento, educación ambiental, puntos, panel operativo, administración,
autenticación y asistente EcoBot.

## Dirección visual
- Paleta forestal, verde hoja, lima suave y marfil cálido.
- Tipografía Manrope para jerarquía y DM Sans para lectura.
- Navegación superior tipo portal comunitario.
- Tarjetas, paneles, formularios, estados y controles con radios y sombras coherentes.
- Diseño adaptable a escritorio, tableta y móvil.
- Se conservaron los IDs, nombres de campos, formularios y selectores usados por app.js.

Este cambio es de presentación; no habilita WhatsApp ni cambia la configuración de servicios externos.
